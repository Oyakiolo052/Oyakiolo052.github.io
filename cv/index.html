    • Supervisors: Prof. Chanchal K. Roy and Dr. Zadia Codabux

    Investigated modern code review as a socio-technical process, focusing on developer satisfaction, code comprehension, and collaboration. Interests

Empirical Software Engineering

Applying repository mining, developer studies, and data-driven methods to understand software development practices, identify challenges, and develop empirically grounded improvements.

Human-Centered Software Engineering

Investigating developer satisfaction, communication, collaboration, cognitive workload, psychological safety, and sustainable participation in software development.

Modern Code Review and Software Quality

Improving code review effectiveness through better reviewer assignment, code comprehension, review feedback, and coordination while supporting software quality and developer experience.

Trustworthy and Accountable AI for Software Engineering

Developing methods to make AI-generated software reviewable, verifiable, reliable, and accountable through independent assurance, risk-sensitive validation, and human oversight.

AI-Generated Code Review and Comprehension

Designing context-aware review assistants that identify relevant dependencies, unchanged files, and repository history to help reviewers understand and validate AI-generated changes.

Human-AI Collaboration in Software Development

Examining how AI coding agents reshape reviewer workload, human judgment, mentoring, knowledge transfer, expertise development, and long-term team sustainability.
