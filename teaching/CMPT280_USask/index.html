Course Overview

CMPT 280 introduces the design, implementation, and analysis of data structures and algorithms using Java and object-oriented programming principles.

The course covers fundamental and advanced data structures, including lists, trees, dictionaries, heaps, and graphs, alongside searching, sorting, and algorithm analysis.

A central emphasis is placed on understanding the strengths and limitations of different data structures, evaluating their computational efficiency, and selecting appropriate structures and algorithms to solve practical problems.

Learning Outcomes

Upon successful completion of the course, students should be able to:

Understand Data Structures

Compare the strengths, limitations, and applications of different collection and graph data structures.

Design and Implement

Implement abstract data types using object-oriented principles, specifications, and reusable components.

Analyze Efficiency

Evaluate algorithm complexity and the efficiency of data structure operations.

Apply Graph Algorithms

Understand and implement tree operations, graph traversal, and shortest-path algorithms.

Select Algorithms

Choose appropriate data structures and sorting algorithms based on computational requirements.

Test Implementations

Apply regression testing and exception handling to assess software correctness.

Course Topics

The course covers the following interconnected areas of data structures, algorithms, and software development.

Linear Data Structures and ADTs

Array-based lists, singly and doubly linked lists, cursors, iterators, stacks, queues, abstract data types, and formal specifications.

Trees and Dictionaries

General and binary trees, tree traversals, heaps, ordered binary trees, AVL trees, hash tables, 2-3 trees, B-trees, B+ trees, trie trees, and k-D trees.

Graph Algorithms

Directed and undirected graphs, graph representations, breadth-first search, depth-first search, and shortest-path algorithms including Dijkstra's algorithm.

Sorting and Algorithm Analysis

Merge sort, quicksort, heapsort, bucket sort, radix sort, statement counting, active operations, Big-O, and Big-Theta notation.

Software Testing

Regression testing, black-box testing, white-box testing, and management of expected and unexpected exceptions.

Teaching and Learning Approach

The course combines conceptual instruction with practical implementation and problem-solving activities.

Lectures and Tutorials

In-person instruction introduces theoretical foundations and reinforces concepts through practical examples.

Pre-class Preparation

Assigned readings prepare students for classroom discussions and problem-solving activities.

Programming Assignments

Individual Java assignments develop understanding of data structures, algorithms, and their behavior.

Quizzes and Examinations

Assessments evaluate conceptual understanding, implementation skills, and independent algorithmic reasoning.

Student Support

Help sessions, course discussions, and instructor communication provide additional learning support.

The course combines continuous coursework with supervised examinations to evaluate practical and conceptual learning.

Programming Environment

The primary programming language is Java (version 8 or later). The course supports IntelliJ IDEA as the development environment.

Students work with Java implementations of abstract data types and algorithms, emphasizing correctness, reusability, and computational efficiency.

Academic Integrity and Responsible AI Use

The course emphasizes independent learning, academic integrity, and the development of foundational programming and algorithmic reasoning skills.

Students were required to complete graded work individually. Generative AI tools, including ChatGPT and similar systems, were not permitted in course assessments under the syllabus policy.

Teaching Reflection

Teaching CMPT 280 reinforced the importance of developing conceptual understanding alongside programming proficiency.

The course provided opportunities to observe how students approach algorithmic problems across programming assignments, quizzes, and supervised examinations.

These experiences inform my broader interest in computing education, particularly the development of independent problem-solving skills in an era of AI-assisted programming tools.
