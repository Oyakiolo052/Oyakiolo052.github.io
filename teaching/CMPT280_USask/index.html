Course Overview

CMPT 280 introduces the design, implementation, and analysis of data structures and algorithms using Java and object-oriented programming principles.

The course covers fundamental and advanced data structures, including lists, trees, dictionaries, heaps, and graphs, along with searching, sorting, and algorithm analysis techniques.

A central emphasis is placed on understanding the strengths and limitations of different data structures, evaluating their computational efficiency, and selecting appropriate structures and algorithms to solve practical problems.

Learning Outcomes

Upon successful completion of the course, students should be able to:

  1. Understand and compare data structures: Evaluate the advantages, limitations, and applications of different collection and graph data structures.

  2. Design and implement data structures: Implement abstract data types using object-oriented programming principles, formal specifications, and reusable components.

  3. Analyze algorithm efficiency: Evaluate the time complexity of data structure operations and algorithms using asymptotic notation.

  4. Apply tree and graph algorithms: Understand, simulate, and implement tree operations, graph traversal, and path-finding algorithms.

  5. Select appropriate algorithms: Choose efficient data structures and sorting algorithms based on problem requirements and performance characteristics.

  6. Apply software testing principles: Use regression testing and exception handling to assess implementation correctness.

Course Topics

The course covers the following topics.

Module Topics
Lists and Iterators Array-based lists, singly and doubly linked lists, cursors, and iterators
Regression Testing Black-box testing, white-box testing, and exception handling
Algorithm Analysis Statement counting, active operations, Big-O, and Big-Theta notation
Abstract Data Types ADT definitions, formal specifications, and object-oriented design
Trees General trees, binary trees, array-based trees, and tree traversals
Dispensers Stacks, queues, and heaps
Non-keyed Dictionaries Ordered binary trees and AVL trees
Keyed Dictionaries Hash tables, keyed AVL trees, 2-3 trees, B-trees, and B+ trees
Advanced Trees Trie trees and k-D trees
Graph Algorithms Directed and undirected graphs, DFS, BFS, and shortest-path algorithms
Sorting Algorithms Merge sort, quicksort, heapsort, bucket sort, and radix sort

Teaching and Learning Approach

The course combines conceptual instruction with practical implementation and problem-solving activities.

Lectures and Tutorials

In-person lectures introduce the theoretical foundations of data structures and algorithms. Tutorials provide opportunities to reinforce concepts and work through practical examples.

Pre-class Preparation

Students complete assigned readings before lectures to support meaningful participation in classroom discussions and exercises.

Programming Assignments

Individual programming assignments provide opportunities to implement data structures and algorithms in Java, examine their behavior, and develop practical problem-solving skills.

Quizzes and Examinations

Regular quizzes reinforce learning objectives, while midterm and final examinations assess conceptual understanding, algorithmic reasoning, and independent problem solving.

Student Support

Students receive additional support through help sessions, course discussions, and instructor communication.

Assessment Structure

The course uses the following assessment components:

Assessment Weight
Programming Assignments 20%
Quizzes 5%
Midterm Examination 20%
Final Examination 55%
Total 100%

The assessment structure combines continuous coursework with supervised examinations to evaluate both practical implementation skills and conceptual understanding.

Programming Environment

The primary programming language is Java (version 8 or later).

The course supports the IntelliJ IDEA development environment. Students work with Java-based implementations of abstract data types and algorithms, emphasizing correctness, reusability, and computational efficiency.

Academic Integrity and Responsible Use of AI

The course emphasizes independent learning, academic integrity, and the development of foundational programming and algorithmic reasoning skills.

Students were required to complete graded work individually. The use of generative AI tools, including ChatGPT and similar systems, was not permitted in course assessments under the syllabus policy.

These expectations were intended to ensure that submitted work demonstrated students’ own understanding and application of the course concepts.

Teaching Reflection

Teaching CMPT 280 reinforced the importance of developing conceptual understanding alongside programming proficiency.

The course provided opportunities to observe how students approach algorithmic problems across programming assignments, quizzes, and supervised examinations.

These experiences inform my broader interest in computing education, particularly how students develop independent problem-solving skills in an era of increasingly capable AI-assisted programming tools.
